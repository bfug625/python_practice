# python_practice

A running log of Python practice exercises and mini-labs focused on fundamentals and data analysis workflows (data structures, parsing, time handling, pandas, and visualization).  
Goal: rebuild fluency, improve problem-solving speed, and demonstrate consistent learning through small, well-scoped projects.

## What’s inside
- **Warmups:** quick reps (lists/dicts/strings, simple algorithms)
- **Fundamentals:** functions, loops, file parsing, error handling
- **Data labs:** pandas workflows (cleaning, grouping, time series basics)
- **Mini-projects:** slightly larger scripts that combine multiple skills

How to run

Most exercises are plain .py files or Jupyter notebooks.

Option A: Run a script
python fundamentals/example.py

Option B: Notebooks

Open the .ipynb files in Jupyter / VS Code.
Conventions (so it stays employer-friendly)
  Exercises typically include:
    problem.md (prompt / requirements)
    solution.py or solution.ipynb
    optional tests/ for small test cases
  Code prioritizes readability: clear naming, small functions, and docstrings when helpful.
  Refactors get a short note in commit messages or in notes/.

Progress log
  I add exercises regularly and try to keep each one small and complete:
    clear input/output
    a couple test cases
    basic edge-case handling
